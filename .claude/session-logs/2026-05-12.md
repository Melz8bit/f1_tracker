## Concepts covered
- Rename destructuring: `{ data: sprintData, isLoading: isSprintLoading }`
- `&&` short-circuit rendering in JSX
- React Fragment `<></>` vs `<div>` — invisible grouping vs DOM element
- Arrow function body: `(x => ...)` single expression vs `(x => { ...; return ... })` block body
- `.filter()` — keeps items where callback returns true
- `?? []` nullish coalescing to guarantee an array type
- `find()` to look up a matching item in an array
- `.at(-1)` — last item in array
- `enabled` option in `useQuery` — dependent/chained queries
- `!` non-null assertion — telling TypeScript a value is definitely defined
- `useQueries` — parallel dynamic queries, returns array of query results
