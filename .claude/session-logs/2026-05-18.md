## Concepts covered
- `.some()` — true if any item matches (complement of `.filter()`)
- `.every()` — true if all items match
- `.map((item, i) => ...)` — second parameter is the index
- `.sort((a, b) => b.x - a.x)` — descending sort; `a - b` = ascending
- `Math.max(...array)` — spread array as individual arguments
- Type guard `(s): s is number => s !== null` — narrows type after filter
- `new Date(str) < new Date()` — compare dates for past/future filtering
- 429 Too Many Requests — API rate limiting from too many parallel requests
- Architecture lesson: one request + client-side grouping beats N parallel requests
